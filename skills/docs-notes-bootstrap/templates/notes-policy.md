# 决策笔记政策

## 记录什么

仅记录会影响未来选择、但代码与正式文档不能充分解释的问题、理由、真实替代方案、代价、否定保证与验证要求。普通机械编辑和调试转录不自动产生笔记；先搜索已有决策所有者，能更新则不重复新建。

## 正式文档关系

docs 拥有现行规则和操作的详细说明；笔记拥有为什么及放弃什么。将稳定知识迁入 docs 后，笔记保留理由并链接 docs，不再复制完整操作说明。晋升知识不等于可以归档该理由。

## 整理与归档

按未来决策价值分类，不按年龄、字数或配额。仍约束安全、兼容、所有权、被反复提议的失败方案的记录保持可检索。只归档完成且不再指导未来、仍有历史价值的已实施记录。
